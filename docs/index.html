Browser mock API

Кнопка Try it out в Swagger использует мок на JavaScript: он возвращает те же статусы и данные, что текущие mock-репозитории в murroom-service.

Из кода страницы запрос можно получить так:

const response = await fetch(new URL("mock/venues", location.href));
const venues = await response.json();

Все пути из контракта доступны с префиксом mock, например mock/auth/login и mock/cart. Это browser-only mock: он работает после открытия этой страницы, но не является внешним HTTP-бэкендом и не предназначен для curl.
